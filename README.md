# 🔭 Astronomy Observation Management System (AOMS)

A Java-based desktop application for managing astronomical observations,
built for Lahore AstroHub club.

## 🏗️ Project Structure
- **backend** — MVC architecture (controller, model, service, database, exception, filehandler)
- **frontend** — CLI interface via MainMenu

## ✨ Features
- CRUD operations for Celestial Objects, Observers, Telescopes & Sessions
- MySQL/JDBC database connectivity
- File-based observation logging
- Custom exception handling
- Analytics engine for observation data

## 🛠️ Tech Stack
- Java 17
- MySQL
- JDBC
- Maven

## 🚀 How to Run
1. Setup MySQL database using `database/schema.sql`
2. Configure DB credentials in `DBConnection.java`
3. Run `Main.java`
